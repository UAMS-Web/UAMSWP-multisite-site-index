The plugin is developed in [UAMS-Web/UAMSWP-multisite-site-index](https://github.com/UAMS-Web/UAMSWP-multisite-site-index). It is based on Multisite Site Index by Nick Halsey; the [README](https://github.com/UAMS-Web/UAMSWP-multisite-site-index#credits) lists the credits.

## Reporting a problem

Open an issue in the [issue tracker](https://github.com/UAMS-Web/UAMSWP-multisite-site-index/issues). Say which release you run (see [Releases](https://github.com/UAMS-Web/UAMSWP-multisite-site-index/releases)), the shortcode or widget settings you used, what you expected and what the page showed.

## Changing the plugin

The path from an issue to a merged change is in [`CONTRIBUTING.md`](https://github.com/UAMS-Web/UAMSWP-multisite-site-index/blob/master/CONTRIBUTING.md). How to run the tests is in the [README](https://github.com/UAMS-Web/UAMSWP-multisite-site-index#running-the-tests).

## Changing this wiki

The pages are kept in [`docs/wiki/`](https://github.com/UAMS-Web/UAMSWP-multisite-site-index/tree/master/docs/wiki) and published by the *Publish wiki* workflow on each release, which replaces the whole wiki with that folder. Change a page through a pull request; an edit made in the wiki itself is overwritten by the next publish.
