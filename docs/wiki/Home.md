UAMSWP Multisite Site Index lists the sites of a WordPress multisite network, with a link to each site and, optionally, its tagline. It puts the list on a page with the `[site-index]` shortcode or in a widget area with the Site Index widget.

This wiki holds the documentation: a walkthrough, a task guide, the reference for the shortcode and the widget, and troubleshooting. The [README](https://github.com/UAMS-Web/UAMSWP-multisite-site-index#readme) keeps an overview, the requirements, installation and how to run the tests.
